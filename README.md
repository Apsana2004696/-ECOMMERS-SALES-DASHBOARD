# E-Commerce Sales Analysis Dashboard | Power BI

## 📊 Project Overview

This project is an interactive **E-Commerce Sales Dashboard** developed using **Microsoft Power BI**. The dashboard provides a clear overview of sales performance, profit, quantity, customers, product categories, payment methods, states, and monthly trends.

The goal of this project is to transform raw e-commerce data into meaningful visual insights that can help businesses understand their sales performance and make data-driven decisions.

## 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- DAX
- Business Intelligence

## 📈 Dashboard Features

- Total Sales Amount
- Total Quantity Sold
- Total Profit
- Average Order Value
- Sales by State
- Profit by Month
- Payment Mode Analysis
- Quantity by Category
- Profit by Sub-Category
- Customer-wise Sales Analysis
- Interactive State and Quarter filters

## 🔍 Key Insights

- Identified high-performing product categories and sub-categories.
- Analyzed monthly profit trends.
- Compared different payment methods.
- Analyzed sales performance across states.
- Identified customers contributing significantly to sales.
- Used interactive filters to explore the data.

## 📂 Dataset

The dataset contains e-commerce transaction information such as:

- Order ID
- Customer Name
- State
- Order Date
- Quantity
- Amount
- Profit
- Category
- Sub-Category
- Payment Mode

## 🎯 Objective

To build an interactive business intelligence dashboard that converts e-commerce sales data into actionable insights using Power BI.
